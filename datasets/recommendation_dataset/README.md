# PLDK-TR Dataset

## Description

The Plant Leaf Disease Knowledge and Treatment Recommendation (PLDK-TR) dataset was developed in this study to support the treatment recommendation stage of the proposed framework.

The dataset covers **26 plant diseases** affecting **11 plant species** and provides structured information for disease understanding and treatment recommendation. It is organized into two main components:

1. **Plant Leaf Disease Knowledge Base**, which contains disease-related information such as symptoms and causal factors.
2. **Plant Disease Treatment Recommendation**, which provides treatment recommendations according to disease name and severity level, including treatment type, treatment name, application method, and precautionary guidelines.

## Contents

- **PLDK-TR_Treatment_Recommendation.csv**
  - Plant disease treatment recommendation table used by the recommendation module.

- **PLDK-TR.docx**
  - Complete documentation describing the dataset structure, tables, and treatment priority strategy.

- **PLDK-TR_References.docx**
  - Reference sources used to construct the dataset.

## Notes

The complete dataset documentation and reference materials are provided to facilitate reproducibility and improve the transparency of the proposed recommendation framework.
