# Segmentation Datasets

Due to GitHub storage limitations, the segmentation datasets used in this work are hosted on external platforms.

--------------------------------
## Leaf Segmentation Dataset
--------------------------------

The leaf segmentation dataset was generated from the publicly available PlantVillage dataset using a semi-automatic annotation workflow. It is available on Kaggle:

https://www.kaggle.com/datasets/memohussein/plantvillage-leaf-segmentation-manual-annotations


The dataset is provided in COCO format and includes training, validation, and testing splits.



--------------------------------
## Lesion Segmentation Dataset
--------------------------------

The lesion segmentation dataset contains manually annotated lesion masks generated from the publicly available PlantVillage dataset. It is available on Roboflow:

https://app.roboflow.com/mariam-n5zbr/lession-f3acm/browse?queryText=&pageSize=50&startingIndex=0&browseQuery=true

The dataset is provided in COCO format and includes training, validation, and testing splits.
